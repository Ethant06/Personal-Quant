# Investory — Glossary (product content)

Terms the product may explain to beginners. Keep definitions short; prefer one concrete example tied to a watchlist company when used in a briefing.

| Term | Plain definition | Example angle |
|------|------------------|---------------|
| Earnings | A company’s report of profit/loss for a period | “Apple reported quarterly earnings…” |
| EPS | Earnings per share — profit divided by shares | |
| Guidance | What management says it expects next period | |
| Acquisition | One company buying another | |
| Inflation | General rise in prices; can affect costs and demand | |
| Interest rate | Cost of borrowing; affects growth companies and consumers | |
| 8-K | SEC filing for major company events | |
| 10-K / 10-Q | Annual / quarterly SEC business + financial report | |
| Macro | Economy-wide forces (rates, inflation, policy) vs one company | |
| Volatility | How much price swings; not the same as “good/bad company” | |

Add rows as briefings introduce new terms. This page feeds Epic D — not a task list.
